# ![kafka-lab](img/banner/kafka_lab.png)

Este repositorio corresponde al trabajo práctico del curso de Apache Kafka y tiene como propósito centralizar el material académico, laboratorios, ejemplos, ejercicios y proyectos desarrollados a lo largo del curso.  
Durante el desarrollo de las actividades se estudiarán los fundamentos de los sistemas distribuidos orientados a eventos, abordando conceptos como event streaming, productores, consumidores, tópicos, particiones, grupos de consumidores y procesamiento distribuido.  
El repositorio también incluye implementaciones prácticas utilizando el ecosistema de Apache Kafka, permitiendo explorar de manera progresiva sus principales componentes, mecanismos de comunicación y patrones de procesamiento de eventos.  
En conjunto, este espacio funciona como un laboratorio práctico de aprendizaje, donde los conceptos teóricos se complementan con ejercicios y experimentos orientados a comprender el funcionamiento de Kafka en escenarios de procesamiento distribuido y arquitecturas basadas en eventos.
